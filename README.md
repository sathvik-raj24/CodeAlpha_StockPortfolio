# CodeAlpha Stock Portfolio Tracker

## About

A simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship.

## Features

- Displays available stocks and their prices
- Allows users to enter stock names and quantities
- Calculates the value of each stock
- Calculates the total investment value
- Handles invalid stock names
- Handles invalid quantities
- Prevents zero or negative quantities
- Displays a final portfolio summary

## Technologies Used

- Python

## Python Concepts Used

- Dictionaries
- Loops
- If-else statements
- User input
- Arithmetic operations
- Exception handling

## How It Works

1. The program stores predefined stock prices in a dictionary.
2. The user selects a stock from the available stocks.
3. The user enters the quantity of shares.
4. The program calculates the value of the selected stock.
5. The user can add multiple stocks.
6. After entering `done`, the program displays the portfolio summary and total investment value.

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python portfolio.py

## Example

AAPL: 5 shares × $180 = $900
TSLA: 2 shares × $250 = $500

Total Investment Value: $1400

## Project Objective

The objective of this project is to create a simple stock portfolio tracker that calculates the total investment value based on user-entered stock quantities and predefined stock prices while practicing Python dictionaries, loops, conditional statements, user input, arithmetic operations, and exception handling.
